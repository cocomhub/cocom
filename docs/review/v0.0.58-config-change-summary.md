# v0.0.57 → v0.0.58 配置变更摘要（上线必读）

> 更新于 2026-08-25。本摘要基于 v0.0.57..7f1b4a9 的配置 diff（`git diff` + `internal/config/*` + `cmd/config_migrate.go` 逐键核对），供从 v0.0.57 升级到 v0.0.58 时对照。
> 详细逐键表见 `.review/v0.0.58-fresh/diff-audit/R2-config-behavior.md`。

## 🔴 破坏性变更（必须处理）

| 变更 | v0.0.57 | v0.0.58 | 影响 | 处置 |
|---|---|---|---|---|
| **默认端口** | 35456（conf 样例）| **8080** | 端口变化 | Dockerfile EXPOSE/HEALTHCHECK 已同步；客户端 `client.server_addr` 需改 |
| **默认监听地址** | 0.0.0.0（对外）| **127.0.0.1**（仅本机）| 远程/容器访问失效 | 需对外访问须显式 `server.listen.http.addr: 0.0.0.0:8080` |
| **archive 默认口令** | `archive@123456`（公开）| **空串** | 空口令 pack/归档直接报 `archive password is empty` | 存量部署若未显式配口令，历史归档用公开口令——须人工核对 `cocom.archive.password` |
| **host/port 顶层键** | 顶层 `host`/`port` | 删除 → `server.listen.http.addr` | 旧配置不再读 host/port | `cocom config migrate` 迁移（注意见下） |
| **storage.backends** | 顶层 `storage.backends` | `cocom.storage.backends` | 顶层不迁移则附加后端全失效 | 跑 migrate 或手工搬迁 |
| **BaiduPCS** | 外置 `metadata.command/commandPath` | 内置库，改 `bduss`/`cookies` | 外置可执行文件方案作废 | 改配置为 `bduss`/`cookies` |
| **http.* 代理** | `http.enable_proxy`/`http.proxy` | `download.enableProxy`/`download.proxyURL` | 代理配置不迁移则失效 | 跑 migrate |
| **COCOM_PORT/COCOM_HOST env** | 支持 | 移除 | 环境变量失效 | 改用 `COCOM_SERVER_LISTEN_HTTP_ADDR` |

## 🟡 `cocom config migrate` 注意事项

- **host/port 迁移补默认 host 为 `0.0.0.0`**：旧配置只有 port 时，迁移产 `0.0.0.0:35456`（对外暴露 + 保留旧端口）——**与安全默认 127.0.0.1 相反**，迁移后需人工改为 `127.0.0.1:8080` 或 `0.0.0.0:8080`
- **重写文件丢注释**：migrate 用 yaml.Marshal 重写，原文件注释丢失 → 先备份
- **`--dry-run` 已实现**：只输出 diff 不写盘（敏感值脱敏为 `***`）
- **写盘权限收敛**：文件存在且权限宽于 0600 时迁移后收敛为 0600 并提示
- **migrate 不覆盖的键**（同路径读取无损失）：`server.*`、`comic.*`、`mongo.*`、`log.*`、`download.*`
- **migrate 未覆盖且键路径变**：`admin.token`（v0.0.57 顶层 → v0.0.58 `server.admin.token`）——旧配置的 token 不会被搬，需手工补

## 🟢 默认值补齐/修复（升级后自动获得）

- `server.shutdown_timeout`（默认 `5s`）、`server.admin.*`、`archive.root_dir`、`client.server_addr`（v0.0.57 均无默认，现补齐）
- `download.maxRunning` 默认 **10**（`pkg/download.Init` 缺省兜底 3 仅当未配置时）
- `log.maxAge=30`/`compress=true` 等日志默认已归一

## ⚠️ 已知文档/样例不一致（不影响运行）

- `comic.download.maxDownloadSize`：conf/cocom.yaml 样例=3，代码默认=5
- `cocom-gen.yaml` 缺 `server.cors.expose_headers`（types.go 有字段，cors.go 消费）
- config-doc-gen 报 8 键缺 config-doc 注释（`cocom.storage.path`、`archive.*` 等）

## 📌 升级操作建议

1. **备份**：`cp cocom.yaml cocom.yaml.bak`
2. **迁移**：`cocom config migrate --dry-run`（预览）→ `cocom config migrate`（执行，`--yes` 跳过 host/port 确认）
3. **核对**：`server.listen.http.addr` 是否符合预期（默认 127.0.0.1:8080）；`cocom.archive.password` 是否与历史归档口令一致
4. **补后端**：确认 `cocom.storage.backends` 已迁移（否则附加后端失效）
5. **日志/权限**：确认配置写盘权限 0600
