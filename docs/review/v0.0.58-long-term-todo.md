## 🔴 高风险（建议尽快修）

### 1. util.Move / util.CopyDir Windows 分支必然失败
- **文件**：`pkg/util/dir.go`（v0.0.57 同存，`git show v0.0.57:pkg/util/dir.go` 证实 4 处 exec.Command）
- **问题**：
  - `Move` Windows 分支 `exec.Command("move", ...)` —— `move` 是 cmd.exe 内建命令，`exec.LookPath("move")` 返回 not found → Windows 上 `cocom server` 归档/恢复（`cmd/server/internal/comic/archive.go`）恒失败
  - `CopyDir` Windows 分支 `exec.Command("robocopy", ...)` —— robocopy 正常退出码为 1（"已复制文件"），`cmd.Run()` 视为错误 → `cocom gallery compare`（--remote-not-exist-auto-verify）在 Windows 上成功也报失败
- **建议**：`Move` 改 `os.Rename`（失败再 exec）；`CopyDir` 对 robocopy 低 8 位判成功，或改 `filepath.Walk` 跨平台统一

### 2. 图片解码无尺寸上限（Decompression Bomb）
- **文件**：`pkg/imaging/image.go`（V1/V2 decode 入口）、`pkg/imaging/webp/decode.go:165`（`make([]byte, w*h)`，w 可达 2^24）
- **问题**：DecodeConfig 后未做 `Width*Height` 上限检查；webp readAlpha comp0 无 16384 上限（与 comp1 不对称）→ 单图可触发 GB 级分配/OOM（服务 DoS）
- **建议**：复用 `maxImageDimension`(20000)/`maxImagePixels`(1e8) 常量，decode 前置检查

### 3. ReDoS（动态正则未 QuoteMeta）
- **文件**：`pkg/comic/storage.go:424,435`（`regexp.Compile("(?i)"+filter.TitlePattern)`）、`cmd/server/internal/tag/default_store.go:352`、`/search` 页 query（C28 定位）
- **建议**：动态部分 `regexp.QuoteMeta`

### 4. maxbody 413 映射条件性
- **文件**：`pkg/middlewares/maxbody.go:27-36`
- **问题**：413 依赖 handler 上报 `*http.MaxBytesError` + `Writer.Status()==200`；多数 handler（ShouldBindJSON/json.Decode）先写 400/500 → 超限返回 400 而非 413
- **建议**：中间件主动 Abort(413) 或 handler 统一还原

### 5. CORS 默认 `allow_origins: *`
- **文件**：`internal/config/manager.go:133` + `pkg/middlewares/cors.go`
- **问题**：默认 `*` 允许任意跨站脚本访问/写（配合未鉴权端点放大风险）
- **建议**：默认改 `127.0.0.1` 或反射本机 origin（D-C 决策：本次不动默认，留待评估）

## Batch D-C 安全警告（v0.0.58 上线注意事项）

按用户决策 **D-C**（不强制鉴权、仅文档警告）。部署公网实例时请注意：

- **未鉴权写端点**：`/api/comic/savePages`、`saveComicInfo`、`download`、`restore`、`saveVideoInfo`、`customLikeToTag`、`settings`（POST/DELETE）、`tags/update`、`batch-add`、`tags/relation`、`tags/like`、`addLikeGroup` 等均为裸端点，无 token/loopback 校验。
- **CORS 默认 `*`**：任意网页可跨域调用上述写端点 → 公网实例数据可被任意网页覆盖/删除。
- **建议**：公网部署必须（1）显式配置 `server.cors.allow_origins` 为可信域名；（2）配置 `server.admin.token`；（3）用反代/Nginx 限制写方法或加 basic auth；（4）`/api/util/webp/install` 端点（返回安装脚本）应禁用或限 loopback。
- 本仓库内联管理员端点 `/api/admin/*` 已有 AdminGuard（token 或 loopback）保护；其余写端点请按上述建议在网关层防护。
